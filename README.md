# TalentScout Manager1

Versão de trabalho do TalentScout Manager, com autenticação MySQL/Hostinger simplificada e acesso de administrador separado da interface pública.

## Instalação
1. Publicar todos os ficheiros na Hostinger.
2. Manter `private/config.php` do servidor se a base já estiver configurada.
3. Se for uma instalação nova, abrir `instalar.php` uma única vez.
4. Requer PHP 8.2+ e MySQL.
